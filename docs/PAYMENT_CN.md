# 链动小铺充值

本分支仅保留链动小铺购买兑换码的充值方式。

管理员在系统设置的购买配置中启用小铺，并为 10 / 20 / 30 / 50 / 100 元档位填写商品链接。用户从 `/purchase` 选择档位，前往小铺购买后，返回 `/redeem` 兑换。本站不会向商品链接追加身份、令牌或金额参数。

设置字段为 `purchase_subscription_enabled` 和 `purchase_subscription_products`。链接校验、兑换码发放及管理员 API 对接见 [外部商城对接说明](ADMIN_PAYMENT_INTEGRATION_API.md)。

原生收银台、支付渠道配置、站内支付订单、退款接口、支付回调及订单定时任务已移除。历史订单、财务审计和返利关联数据保留在数据库中，不做删除迁移。普通余额、兑换码、用户订阅和返利功能继续保留。

部署此变更前，应完成旧支付系统仍在处理的订单或退款。本次代码调整不会修改线上数据。
