# Sub2API 2.0.61-personal.2

- 外部小铺充值采用 10、20、30、50、100 元五个固定档位，管理员可分别配置对应商品链接；未配置的档位不可购买，无自定义金额。

- 修复 GPT/OpenAI 透传分组在模型广场消失的问题：有可调度 OpenAI 账号时采用默认展示模型，并继续应用分组白名单和渠道价格。原有路由模型目录语义保持。
- 沿用 personal.1 的上游 2.0.61 同步、安全视频下载和滚动条修复。无新增迁移或依赖；保留既有计费、分组倍率、账号归属和 VPS 更新策略。
