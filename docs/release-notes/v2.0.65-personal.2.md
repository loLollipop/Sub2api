# Sub2API 2.0.65-personal.2

优化充值中心的布局与购买指引，保持现有支付及兑换逻辑不变。

## 优化

- 小铺与站内支付使用独立界面，不为另一种支付方式预留空白区域。
- 小铺提供 10 / 20 / 30 / 50 / 100 元固定档位、购买摘要、三步充值指引、常见问题与兑换入口；明确区分人民币商品金额和美元账户余额。
- 桌面左右卡片底部对齐并保留统一底部间距，移除右上角小铺标识；改善移动端、深色模式、英文、长用户名及键盘操作体验。
- 调整站内支付视觉样式，保留手续费、币种、订单恢复、微信续付、充值中心和移动端支付按钮行为。

## 升级注意

- 小铺仍按每档管理员原始商品链接打开新标签页；购买后需返回系统兑换，不自动入账、不创建站内订单。
- 无新增迁移或依赖；不修改用户余额、分组倍率、账号归属、支付配置或商品链接。
