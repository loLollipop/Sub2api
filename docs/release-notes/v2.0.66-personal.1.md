# Sub2API 2.0.66-personal.1

同步审查后的上游 2.0.66，并修复充值中心在缩放和较矮桌面窗口中需要滚动的问题。

## 更新

- 同步网关重复模型校验：请求出现不同的顶层模型候选时，在路由、出站和计费前拒绝；相同模型重复填写仍可使用。覆盖 HTTP、图片/视频请求及 Responses WebSocket 首帧和后续轮次。
- 补齐审查发现的请求类型伪装缺口：整份有效 JSON 不再被伪造的 multipart 类型隐藏，重复模型校验与分组白名单使用正确候选；真正的 multipart 上传保持原有解析。
- 充值中心桌面顶部标题与账户信息合并为一行，按窗口高度压紧卡片间距与内边距；常见问题和购买提醒默认折叠，可通过鼠标或键盘展开。
- 默认说明收起时，截图对应缩放尺寸及常见笔记本视口可一屏显示购买和兑换操作，左右卡片底部继续对齐；手机、窄窗口或展开说明时保留自然滚动，不裁切内容。

## 保留与升级注意

- 保留五档小铺独立商品链接、人民币商品金额与美元余额区分，以及原有站内支付、兑换、模型广场、滚动条和会话调度兼容修复。
- 历史暂缓的 DSML/全局标签解析、明文思考历史及 Grok 拒答计费变更仍不接入，具体原因见 `maintenance/upstream.lock.json`。
- 无新增数据库迁移、依赖或部署脚本变更；不修改余额、倍率、账号归属、管理员支付配置或商品链接。可通过既有受控更新器回滚上一版程序。
