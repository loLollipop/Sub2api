# Sub2API 2.0.66-personal.2

调整充值中心的空间分配，让余额信息更好找，购买与兑换提醒直接可见。

## 更新

- 移除充值中心顶部的账户卡片，将账户名称、美元余额和兑换到账说明移到左侧金额选择区内。
- 三步指引改为紧凑的编号流程，不再自动撑满卡片高度；窄屏自动改为纵向排列。
- 购买与兑换提醒常驻显示，不再需要点击展开；常见问题保留可通过鼠标或键盘展开的形式。
- 针对较矮桌面窗口调整间距，默认内容在 1280×640 及常见笔记本尺寸可一屏显示，左右卡片底部对齐；手机、窄窗口、展开常见问题或超长内容仍可自然滚动。
- 保留五档独立商品链接、原地址新标签页打开、人民币商品价格与美元余额区分，以及原有站内支付和兑换流程。

## 验证及升级边界

- 发布前本地支付相关 183 项测试、20 个隔离浏览器场景、类型检查、构建和独立代码复核通过；公开服务部署后另行检查服务状态及静态资源，不执行真实购买或兑换。
- 本次仅涉及充值组件展示、回归测试和版本说明，无新增数据库迁移、依赖或后端业务逻辑变更，不修改客户余额、倍率、账号归属、管理员配置或商品链接。
- 沿用受控 VPS 更新器，保留上一版程序及部署前数据库和运行配置备份；应用自动替换自身继续禁用。
- 既有上游同步边界、暂缓功能及重复模型处理限制保持不变，见上一版说明及 maintenance/upstream.lock.json。
