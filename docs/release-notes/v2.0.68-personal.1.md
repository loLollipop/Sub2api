# Sub2API 2.0.68-personal.1

同步上游 2.0.67–2.0.68 及锁定 main 的 Go / HTTP/2 安全维护更新。

## 更新

- DeepSeek 请求中的重复结构化工具调用及结果仅保留第一次，覆盖 HTTP 入站、Responses WebSocket 后续轮次和所选账号出站处理；保留原调用 ID，避免重复执行工具。
- OpenAI 兼容 `/v1/messages` 恢复分组分发开关；Grok 和国产平台的既有豁免保留。
- 生图入口及服务解析拒绝不同的重复 model 候选。
- 配置 Key 创建频率、用户/分组 RPM 或 Key 周期额度后，相关计数或用量读取失败会拒绝操作，防止已配置限额失效。
- Go、CI 和构建镜像统一升级至 1.26.9，并更新相关 `golang.org/x` 依赖；客户端 HTTP/2 使用标准库配置。

## 保留与暂缓

- 保留个人充值页、支付与兑换、商品链接、账户归属、原有 MIME 模型校验、会话延续和工具转换改动。
- DeepSeek inline DSML / 全局 analysis 与 summary 标签解析及回复重写继续暂缓；此次只接入结构化请求去重。上游 v2.0.67 说明描述的是上游行为，不能视为个人版已启用这些暂缓功能。
- 另外两项既有暂缓功能及完整原因仍记录于 `maintenance/upstream.lock.json`。
- 服务端 h2c 标准库迁移暂缓，以保留 HTTP/1 与 h2c 独立空闲超时。异步生图多分组入口权限放宽也暂缓，待目标分组平台及审计策略覆盖完整后再接入；保留原有准入限制。
- 无数据库迁移或业务数据转换；发布前仍需通过 CI、安全扫描及受控部署验收，应用自更新保持禁用。
