# Sub2API v2.1.11

## 按上游同步质量检测模块

- 导入二改上游 `kiss-kedaya/sub2api` 的 `95db8e604`：删除鹈鹕视觉审核，并把掺水检测配置、HTTP 合约、停止策略与脱敏提取为独立模块。这是上游本身的更新，不是额外自定义检测方案。
- 保留上游默认关闭策略。新建、重置及 API 省略开关时不启用质量检测；历史鹈鹕、空或未知 provider 的计划不会自动升级为向掺水服务发送密钥的授权。
- 提交或轮询前重新核对计划授权；关闭、删除或修改旧快照以及数据库读取失败时不执行该次外部请求。
- 界面明确提示：手动开启掺水检测后，会把被测账号的上游地址、完整 API key 和模型发送给所配置的检测服务，请仅使用可信服务。已经被服务接受的请求不能撤回。
- 历史鹈鹕暂停保持显式管理员恢复，不自动恢复人工停用账号；维护步骤见 `maintenance/notes/upstream-quality-default-off-20261012.md`。
