# Sub2API v2.1.12

## 精选原项目正确性与安全修复

- 参考原项目 v0.2.14 / v0.2.15，移植 16 项适合当前二改架构的修复。具体来源及保留策略记录在 `maintenance/original-backports.json`；不进行覆盖式合并，不引入新平台或数据库重构。
- 补齐 WebSocket 透传的图片输入/输出用量分类与工具用量兜底，保留逐轮一次结算和缓存计数语义。
- 修复原生 Anthropic 缓冲响应的负索引边界及 Antigravity 非流式 thinking 签名字段。
- 修复远程 Codex API-key 模型发现、普通及固定目录的账号映射、未改变响应的 ETag 保留和 `service_tiers` 数组格式。
- 已注册的裸 API 路径不再误入前端页面；修复智谱监控地址和健康分数最小请求样本条件。
- Docker 新安装不再用固定管理员邮箱覆盖已有随机生成逻辑；已有管理员不受影响。

## 后台交互修复

- 模型测试搜索框只保留圆角外层焦点提示，去掉重复边框；其他控件的键盘焦点提示保留。
- 分组倍率加载期间及加载失败后禁用添加草稿，避免加载结果覆盖新编辑；隔离切组、关闭和重开后的迟到加载与保存结果。
- 运维设置加载完成前禁止保存，隔离旧弹窗请求；保存请求保持串行，避免误关闭新弹窗或丢失新草稿。
- 修复科学计数价格、零倍率显示、透传规则开关返回状态及 RPM 整数校验，并将相关回归测试纳入持续集成。

## 兼容与部署

- 无依赖或数据库迁移变更。保留 1 元 / 1 刀、0.15 计费、固定小铺档位和充值界面、透传 429 / 满并发切号、默认关闭的外部质量检测与发送前授权检查。
- 继续使用数字版本、固定提交构建与双哈希校验；部署采用只读迁移预检、连续就绪检查和旧版本回滚保护，不开启内置自动更新。
