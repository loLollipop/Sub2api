# Sub2API v2.1.13

## 独立混合模型平台

- 新增 API-key 专用的 `Mixed / 混合平台`，用于 NVIDIA、DeepSeek 等同一接入站提供多种模型的账号；不改变原有 OpenAI、Anthropic、OAuth 和国产平台身份。
- 同一分组与密钥可接受 Responses、Chat Completions 和 Anthropic Messages 文本及工具调用，通过现有转换器返回客户端请求的格式。
- 优先使用通用 Chat Completions；只有明确的协议拒绝且尚未输出响应时，才有限尝试其他协议。每种协议最多一次，不把单模型失败写成账号级能力。
- 混合平台请求禁止重定向，取消请求及时释放上游连接；流错误和未完整结束的响应不得伪装成完成或重复请求。
- 后台支持混合平台账号、分组、渠道和平台额度；Messages 认证方式可选择 `x-api-key` 或 `Authorization: Bearer`。Codex 配置支持远程模型目录，并提供可替换的千问示例模型。

## 保留现有计费

- 沿用现有模型官方价库、已有显式定价来源和分组/用户/账号倍率，不新增统一混合平台价格。
- 默认计费按实际发送的模型身份查价，不借用客户端 GPT/Claude 别名猜价；既有缺价告警和零成本记录保持不变。
- 转换保留 DeepSeek 缓存命中和 Anthropic 5 分钟/1 小时缓存写入明细，避免重复计费或丢失类别；保留既有金额精度和 DeepSeek 峰谷策略。

## 部署与边界

- 新增迁移 `255_add_mixed_platform.sql`，只扩展平台 CHECK 约束，不自动搬移账号、分组、余额或用量。
- 现有账号切换须独立备份并受控迁移，保留账号 ID、客户端密钥、模型映射、倍率和历史记录；正式成品仍通过双哈希校验及只读迁移预检部署。
- 本次混合平台仅覆盖 API-key 文本 HTTP 协议及工具调用，不新增 OAuth、WebSocket、compact、图片、音频或搜索支持。
- 原有透传与限流/并发切号、小铺充值界面及默认关闭的外部质量检测保持不变。
