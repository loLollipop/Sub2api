# v2.1.14

## 国模接入与模型同步

- 新建 API-only 国产模型账号和分组统一使用“国模”入口，沿用 `mixed` 平台标识；已有供应商账号仍可编辑和筛选。
- 恢复国模上游模型同步，并在账号创建后保存已预览模型的能力信息。
- 为认可的供应商模型前缀添加安全简名，保留原始模型 ID、实际转发目标、分组白名单和显式映射；有歧义的简名不自动生成。
- 继续使用现有模型官方价库和实际转发模型计费，不修改价格、倍率、账号凭证或 API Key。

## 流式请求可靠性

- 修复透传请求取消后仍可能无限等待的问题，断连后在固定预算内收集实际 usage。
- 修复响应头与响应体阶段心跳交接，按真实上游读取活动判断流闲置，避免工具转换缓冲导致误判。
- 上游异常结束时明确交付失败终态；完整终态缺少 SSE 空行且触发闲置超时时补齐边界。部分文本或工具输出不自动重放。
- 保留现有闲置超时配置语义：配置为 0 时，正常连接仍可持续等待上游。

## 部署与验证

- GitHub 制品下载增加连接和总时间上限，回滚期间保护重复取消信号。
- 增加国模目录、真实工具流、终态边界、取消、心跳及并发回归测试。
- 本轮生产发布使用带私有恢复备份与只读模型目录验收的受控部署流程。
