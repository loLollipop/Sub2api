- 创建和编辑 API Key 时，将国模分组归入“国产模型”；Gemini、Grok 等继续归入“其他”。
- 导入国产模型账号时显示 DeepSeek + Kimi + GLM + MiniMax + MiMo，并使用已有品牌图标，兼容移动端、深色模式和键盘操作。
