# Sub2API 2.1.16

- Mixed Group 统一导入多模型 API 账号，复用原有 OpenAI、Anthropic 等调用实现；协议回退仅在明确的接口不支持时进行。
- 修复 Mixed 模型测试把空响应误判为成功的问题，将传输进度与模型回复分开显示。
- 创建 Key 时按 OpenAI、Claude、国产模型、其他四类筛选可用分组及模型，分类互不重叠；旧 Key 保留原有完整访问范围。
- 补齐已有 ChatGLM、CogView/CogVideo、豆包、Yi、文心、星火、混元等国产模型的分类与对应厂商倍率。
- Mixed Group 使用独立的厂商计费倍率，不叠乘总分组倍率；未配置厂商默认 1 倍，显式 0 有效，用户专属倍率优先。官方模型基础价格不变。
- 分组选择器与模型广场展示对应厂商/计费身份的倍率和价格，补齐在途额度预留、倍率缓存及持久化认证失效。
- 增加 Mixed 标识及协议、权限、计费、并发缓存、界面回归覆盖。

升级包含数据库迁移 256、257（新增 Key 分类、Mixed 厂商倍率字段及认证缓存失效条件），表级锁等待上限为 5 秒；不自动回填旧 Mixed 倍率。生产升级前应备份数据库，并先应用、校验迁移。
