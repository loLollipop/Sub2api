# Sub2API 2.1.17

本次按原版与二改仓库的累计更新选择性同步，保留本项目的 Mixed、厂商倍率、模型访问分类和固定金额小铺充值。更新检查按各仓库的提交记录判断，不再把不同仓库的版本号直接比较。

- 修复 Mixed 实际调用与连通性测试链路不一致：优先复用调用方的原生协议，仅在明确拒绝该接口且尚未输出时使用已有兼容链路。补齐 Responses 形状的 Chat 请求、工具历史和输出上限处理。
- 官方 DeepSeek、Kimi、GLM、MiniMax 接入复用原供应商实现；多模型中转账号保留同源协议适配和密钥发送限制，不重复导入账号。
- 同步供应商目录、Cline/Command Code、Vertex API Key/Service Account、Haiku 5.5、Gemini/Antigravity 模型及协议兼容更新。
- 同步账号错误冷却范围、模型映射、上游计费归因、长上下文和渠道默认价格修复；保留 Mixed 厂商独立倍率及用户专属倍率优先规则。
- 修复 Codex 不同工作区导入被误合并；补齐前端弹窗、异步表单、验证码、通知和内置支付离页生命周期问题。
- 补齐后台请求账号信息、单请求输出速度统计、请求 ID 查询索引和相关查询边界。
- 同步 TypeSafe/System One 原生能力。外部质量检测与内容审计保持默认关闭，外发前重新核验授权；TypeSafe 平台额度使用现有通用持久化流程。
- 升级 Go 工具链和 SheetJS，保留精确锁定及导出回归。

未纳入 LinuxDo 邀请传递、多邀请码扩展、正文 DSML 猜测解析、服务端 h2c 生命周期替换，以及已回退的自建账务对账、日志、冻结价格和图片 CAS 机制。完整选择性同步边界见 maintenance 中的记录，不宣称两边仓库全量合并。

Gemini 显式缓存管理仅保留基础协议和数据结构，完整 CRUD 与存储费结算尚未启用；普通 Gemini 请求不受影响。

升级包含自 v2.1.15 之后的追加迁移。生产升级需先备份数据库、演练迁移并校验正式发布二进制，运行实例继续使用迁移校验模式和禁用在线自替换策略。
