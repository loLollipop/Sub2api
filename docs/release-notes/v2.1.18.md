# Sub2API 2.1.18

撤回本项目自建的 Mixed 聚合方案，恢复原有独立平台入口和调用链路。

- Kimi、智谱 GLM、DeepSeek、MiniMax 恢复独立的账号、分组和 Key 选择入口；保留 OpenAI、Anthropic、Gemini、Grok、Antigravity、Command Code、Cline、TypeSafe 等原生能力。
- 删除 Mixed 专属协议探测与回退、流式处理、按模型厂商倍率及 Key 四类模型访问范围；调用继续使用各平台已有实现和原生兼容转换。
- 保留普通模型映射、Composite 路由、分组模型白名单、官方价格库、分组及用户专属倍率、固定金额小铺充值和上游更新检查。
- 保留原生调用的工具历史、最终请求余额预授权、连接测试和模型同步回归；恢复 Cline、Command Code 的正式 Messages 调度和原始模型名，不增加另一套聚合路由。

升级注意：历史迁移文件及兼容列不改删。已有 Mixed 账号／分组及非 `all` 范围的 Key 不会被启动程序静默扩大权限或猜测迁移，需维护者备份后显式转为原生配置，否则将明确拒绝。普通原生账号和分组无需迁移，用户余额及历史用量不换算。

不引入 LinuxDo 邀请传递、多邀请码扩展，以及此前撤回的自建账务对账、日志或冻结价格机制。外部质量检测、内容审计的默认关闭和授权边界保持不变。
