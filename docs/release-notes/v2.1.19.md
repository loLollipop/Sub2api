# Sub2API 2.1.19

修复 Responses 请求通过 Chat Completions 兼容链路时，空流被错误标记为成功、没有切换账号的问题。

## 修复

- 未产生有效输出的空流、仅结束标记、无效数据和可重试上游错误，复用现有账号切换逻辑，不再生成空的成功响应。
- 已输出文字、推理或工具调用后发生截断，明确返回流式失败，不伪造完成，也不自动重放已经开始的工具调用。
- 保留正常拒答的完整 Responses 事件，避免将拒答误判为空响应。
- 兼容上游以 HTTP 200 返回的多行 JSON 错误，在既有限额内读取并保留原有请求错误分类。
- 流中容量拥挤错误沿用现有客户端错误码处理，监控保留原始错误，财务错误继续脱敏。

## 验证

- 新增真实第二账号请求、全池空响应耗尽、部分输出不重放、拒答、多行 JSON 和容量错误回归。
- 相关服务与处理器回归、完整协议兼容单元测试、后端构建及静态检查通过。

## 升级注意

无需新增配置或数据库迁移；账号平台、模型映射、价格与倍率不变。原有 Messages 和直接 Chat Completions 调用链保持不变。
