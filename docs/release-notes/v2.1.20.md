# Sub2API 2.1.20

同步原版 v0.2.17 与二改 v2.1.17 的已审查更新，保留本地充值、原生厂商、0.15 计费及退款事务。

## 更新

- 补齐 Responses HTTP、SSE 和 WebSocket 输出中的时间字段，保留透传原帧、空响应账号切换及财务错误脱敏。
- 改善 Gemini 思考预算、档位、摘要和签名重试兼容，按实际发送的思考档位计费。
- OpenAI OAuth/setup-token 账号停用已退休的 GPT-5.5；API Key 及显式替代模型映射继续支持。同步适配 compact 调度、模型目录和别名缓存。
- OpenAI API Key 的 Messages 入口支持既有搜索模拟配置，保留原生 Anthropic 转发优先级。
- 自定义错误按匹配规则临时停调 30 天；既有认证、限流和供应商专用策略保持优先。
- 完善支付宝退款查询、易支付查询与通知校验、Stripe 同订单密钥恢复及支付返回地址校验。

## 验证与升级

本地后端完整单元测试、静态检查和嵌入式构建通过；前端 3066 项测试、类型检查、ESLint、国际化检查及生产构建通过。发布另经 GitHub CI 和安全检查。

无需新增配置或数据库迁移。生产继续使用 `DATABASE_MIGRATION_MODE=validate` 和 `UPDATE_STRATEGY=disabled`，由现有受控更新器安装本仓库校验后的发行包。

已知既有问题：整份订阅退款在网关异步确认失败时，可能无法自动归还已撤销的订阅权益；仍需单独修复。详细同步边界见 `maintenance/notes/upstream-sync-20261017.md`。
