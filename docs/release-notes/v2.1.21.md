# Sub2API 2.1.21

选择性同步二改 v2.1.27 的安全、DeepSeek 独立工具和界面更新，保留本地原生厂商、计费及充值功能。

- 加固 SMTP、CRS、管理员账号测试与余额探测，限制私网目标并阻止重定向；第三方嵌入页不再携带登录 JWT。
- 输入费用预留默认至少估算 4096 token，可配置错误时拒绝准入；最终费用仍按原有结算规则计算。
- 增加 DeepSeek API Key 的独立 Search/Fetch 入口，使用现有分组搜索价格及强制 usage 结算。
- 用量刷新更新相对时间范围，移动端支持排序；账号弹窗及 xlsx 按需加载，补齐首次打开初始化。
- 优化请求字段扫描，清理 DeepSeek 不支持的推理参数；审核日志展示最后一轮用户输入，图片仅记录数量。
- 地区访问限制使用 HTTP 451 双语说明页，附官方法规参考链接。
- 修复 WebSocket 透传在租约丢失时的关闭码竞态，稳定返回重连提示。

无需数据库迁移或依赖升级。管理员私网探测和 SMTP 内网目标将被拒绝；私网 CRS 需在 CRSHosts 精确指定。自动 DeepSeek 搜索执行、分组专用搜索凭据和 DSML 扩张暂缓，具体边界见 `maintenance/notes/upstream-sync-20261018.md`。

本地完整后端单元测试、Go vet、嵌入前端的服务构建已通过；前端 385 个测试文件、3082 项测试，以及 ESLint、类型检查、语言完整性和生产构建已通过。地区说明页的六项离线检查与桌面、移动端检查通过。财务、安全与审核队列的独立审查已完成；Linux 集成、race 和静态检查由 GitHub CI 验证，全部通过后发布。

既有订阅退款异步失败后的权益恢复问题仍需单独修复。生产继续使用受控更新器、数据库 validate 模式和禁用应用自更新。
