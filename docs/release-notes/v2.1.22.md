# Sub2API 2.1.22

选择性适配二改 v2.2.0 的兼容性和管理界面修复。

- 增加敏感资料提交检查，覆盖测试与文本资源，报告不回显凭据。
- 补充独立搜索低倍率结算及 alpha/search 专用价格回归，维持现有计费行为。

无需数据库迁移或依赖升级。DeepSeek DSML、自动搜索、分组专用搜索凭据及 Grok 新封锁/收费改动仍暂缓，适配范围见 `maintenance/notes/upstream-sync-20261019.md`。

本地完整后端单元测试、Go vet、嵌入前端服务构建、前端生产构建、分组选择器测试及敏感扫描均已通过。Linux 集成、race 和安全检查由 GitHub CI 验证后发布。
