# Sub2API v2.1.3

- 同步经审查的上游 2.0.68 → 2.1.3 差异，保留本地账号池隔离、充值界面、工具去重与会话历史补丁。
- 使用记录支持请求 ID 搜索和独立折叠的在途列表；显示预留金额与运行时长。后台快照与请求状态隔离，Redis 刷新/清理原子化，筛选和翻页丢弃过期响应。余额预留默认仍关闭。
- 修正旧式 function 调用 ID 配对、thinking 空 signature、拒绝回答的 Chat 转换、OAuth web_search 历史与 Responses Lite 兼容、加密历史重试、WebSocket 后续轮次价格刷新和 Grok 空响应重试。
- 新发版标签使用 `vX.Y.Z`；历史 `-personal.N` 发行版继续支持排序和回滚。
- 包含 2.1.3 的 HTTP 环境复制兼容与 Gemini 真实目录。请求 ID 使用现有索引支持的完整 ID 查询，支持上游 ID 和裸 client/local ID，通配字符按字面处理。Responses 原生账号粘性保持本地能力感知与续接保护实现。
- 暂缓 Cline/Command Code 接入及对应迁移 255：凭据目标和映射模型路由尚未通过验收。暂缓 Honeypot 扫描拦截/封禁：会误拒合法业务查询。本次未导入新数据库迁移；不包含此前暂缓的 Grok 拒绝计费、明文 reasoning 历史、DeepSeek DSML、服务端 h2c 配置迁移及异步生图多分组入口放宽。具体理由见 `maintenance/upstream.lock.json`。

延期 256a/256b 请求 ID 索引迁移及片段搜索，直到扩展缺失及无效并发索引恢复通过验收。本次保持无数据库迁移。Opus 5.5 新严格校验因模型映射绕过/误拦截暂缓，既有验证保持。

部署前仍须备份数据库和运行配置，保持 `DATABASE_MIGRATION_MODE=validate` 与 `UPDATE_STRATEGY=disabled`，只使用本仓库校验后的制品。受控更新支持执行前固定二进制哈希，并在外层验收与回滚期间保持同一排他锁。
