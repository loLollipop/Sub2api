# v2.1.31

首页与控制台站点文字统一使用渐变橙色，首页按钮、背景光晕和亮暗主题对齐控制台，用户头像统一为圆形。根滚动容器预留滚动条空间，修复弹窗打开或关闭时背景正文和固定顶栏横向抖动，保留嵌套弹窗的滚动锁及焦点恢复。

模型广场按分组展示，同名模型在不同分组保留独立报价。品牌识别与接入协议分离，OpenAI 兼容格式接入的国模按模型名称显示对应品牌。展示价与官方参考价跟随渠道计费身份，模型专属分组图片价卡优先于通用图片档位价；保留阶梯、分时、用户和图片专属倍率及详情。修复刷新后不兼容筛选组合造成的空列表和键盘焦点问题。

管理侧栏去掉分类标题，安全审计和兑换中心使用无箭头的内嵌展开菜单，子项采用更小字体及缩进。邀请、返利、提取记录整合为“邀请返利”三个页签，保留旧链接重定向。管理端个人区只显示 API 密钥和个人资料，管理员访问用户路径时显示对应的用户导航；保留角色权限校验和原有业务功能。

本版本无数据库迁移或依赖升级，不修改实际扣费流程。发布二进制及 `ghcr.io/lolollipop/sub2api:2.1.31` 由本仓库 GitHub Actions 构建。
