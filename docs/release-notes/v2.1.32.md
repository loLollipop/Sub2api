# v2.1.32

移除渠道定价页面、管理入口及渠道管理 API，旧页面链接转至分组管理。分组表单的官方参考价查询迁至分组 API。保留现有渠道兼容数据与转发适配，包括已启用的图片生成桥接，不修改分组定价、官方参考价和实际扣费流程。

管理端侧栏去掉“我的账户”分类标题，保留 API 密钥与个人资料。折叠时同步收紧横向宽度和纵向间距，展开平顺恢复；移动端触控尺寸与减少动画设置继续生效。

模型广场仅展示所选分组包含的模型品牌，切换分组或刷新时自动清除失效品牌。移除单独倍率筛选，有效倍率直接跟随分组名称展示，包含用户专属倍率与零倍率。

无数据库迁移或依赖升级。发布二进制和 `ghcr.io/lolollipop/sub2api:2.1.32` 由本仓库 GitHub Actions 构建。
