# v2.1.33

个人资料页采用集中展示身份与账户概况、下方分栏设置的排版，沿用站点橙色与半透明主题。头像、昵称编辑继续通过弹窗操作，账户概况展示余额、累计实际消费和 API 请求次数；金额保留至四位小数，加载失败时保留明确提示。

登录方式只展示站点已启用的提供方，操作按钮统一为“绑定”，保留绑定状态、邮箱验证码与解绑流程。未启用的双因素认证和 Passkey 不再占位，启用后仍可正常设置。余额提醒与登录方式收进账户设置，账户安全独立展示，并适配窄屏和深色主题。

管理端版本号移至 GGBond 旁，以略小的纯文字展示。悬浮可查看当前版本、上游原仓库和二改仓库的正式发布状态，支持刷新及键盘访问；不展示回退下拉选项。

无数据库迁移。发布二进制及 `ghcr.io/lolollipop/sub2api:2.1.33` 由本仓库 GitHub Actions 构建。
