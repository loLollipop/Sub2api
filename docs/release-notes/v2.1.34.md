# v2.1.34

选择性适配原版 v0.2.18 与二改 v2.2.20，保留现有界面和链动小铺充值流程。

- Grok 视频自动轮询设置 24 小时预算，任务丢失或过期后保留未决预留，等待确认成功或明确失败；余额耗尽时仍可查询归属明确的既有任务，结算和退款保持幂等。
- 安装加密密钥持久化到数据库，已有显式密钥保持原值；冲突、无效密钥或无法解密的历史凭据会阻止启动，避免重启后丢失密文访问能力。
- 所有用户关闭双因素认证均需当前认证器动态码，保留启用流程的邮箱或密码校验，并避免关闭请求正文进入审计记录。
- Codex 默认使用 CLI 身份，改进空内容事件和 overload 重试；一旦观察到用量便禁止新增重放，保留断流、超时和缓存超限时的用量记录。
- 完善依赖审计报告完整性校验，移除未使用的图标及其依赖树，固定 SheetJS 下载完整性。

新增迁移 `270_media_billing_reconciliation.sql`，扩展媒体任务状态与订阅预留索引。升级前备份数据库和运行配置，保留原加密密钥；回滚不恢复运行中的数据库快照，也不更换密钥。

本地前后端构建、类型与静态检查、真实 PostgreSQL 集成以及后端 service 全量 18,370 个测试及子测试通过。发布二进制及 `ghcr.io/lolollipop/sub2api:2.1.34` 由本仓库 GitHub Actions 构建，线上验收另行记录。
