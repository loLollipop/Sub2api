# v2.1.35

选择性适配二改 v2.2.24，修复 Gemini 原生协议兼容性并优化双重验证，保留现有界面、计费规则和链动小铺充值流程。

- Gemini 原生接口在 adaptive 或未指定协议时直接使用原生上游，保留搜索、思考签名、缓存及 grounding 等字段；显式设置的兼容协议继续桥接。
- 修正 Gemini 专用地址、部署前缀及模型目录匹配，原生账号的别名目录使用真实上游元数据，保留实际错误和模型授权边界。
- 统一六位验证输入，支持前导零、全角数字、粘贴和自动填充；阻止重复验证，失败后可清空重试。
- 改善管理员二次验证与父窗口的层级、键盘焦点和关闭行为，隔离旧请求响应，保留启用及关闭双因素认证的既有身份验证要求。

兼容提醒：仅提供 OpenAI 接口的 Gemini 中转，应显式选择 chat_completions 或 responses。未指定协议的原生 Gemini 请求现在使用 Google 原生格式。

本次没有数据库迁移。后端定向回归 1,439 个测试及子测试通过；前端相关回归去重 397 项通过、1 项原有跳过，类型、静态检查和前后端生产构建通过。发布二进制及 `ghcr.io/lolollipop/sub2api:2.1.35` 由本仓库 GitHub Actions 构建，部署验收另行记录。
