# v2.1.36

选择性适配二改 v2.2.25–v2.2.29 中的视频查询和 Anthropic 缓存修复，保留现有界面、计费规则和链动小铺充值流程。

- 视频任务查询区分不存在或归属不符、来源账号永久失效和临时读取故障；使用来源账号的最新凭据，临时故障可稍后重试，不自动重建任务。
- Chat Completions / Responses 转 Anthropic 保留缓存标记和结构化工具结果，统一缓存 TTL、断点数量和所需请求头处理，保留最终模型映射、输出限制及 thinking 兼容。
- 补齐工具结果中的内联 PDF 和 UTF-8 文本文档转换，保留附件标题、混合文本及缓存标记；无法共享的文件 ID 或损坏附件在转发前明确报错。

本次没有前端、依赖或数据库迁移变更。后端本地回归 3,057 个测试及子测试通过，嵌入式服务构建和敏感信息检查通过；完整 Linux CI 与部署验收另行记录。发行二进制及 `ghcr.io/lolollipop/sub2api:2.1.36` 由本仓库 GitHub Actions 构建。
