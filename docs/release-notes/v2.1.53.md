## 修复

- 使用记录优先展示输入/输出 Token、费用和延迟，减少查看关键用量时的横向滚动；邮箱保持完整单行，保留原有字号和舒适列宽。
- 表格间距根据容器实际宽度和可见列数自动调整，修改列设置后即时生效；移除管理端强制 1680px 最小表宽，保留已保存的列设置，次要信息仍可横向滚动查看。
- Images 的 `frame_count`、`frame_duration_ms` 接受 `"8"`、`"200"` 这类十进制整数字符串。API Key JSON 转发时规范成数字，OAuth 使用解析后的整数；生成与编辑入口均支持。
- 保留 GIF 参数精确整数、非负数和溢出校验，以及已有合成和资源预算，拒绝非法类型和值。
