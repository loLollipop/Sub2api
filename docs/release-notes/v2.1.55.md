选择性同步二改 v2.3.16–v2.3.17，修复注册信息泄露、图片失败误计费和 Grok TTS 文本不一致，更新 CC Switch 客户端导入。

## 修复与更新

- 注册验证码发送对已注册邮箱及其别名返回与正常发送一致的消息和倒计时，避免通过响应探测账户；不向这些地址发送邮件，保留人机验证及其他失败处理。
- 管理端使用记录第一页最多补充 50 条筛选后的在途请求，避免大账号池撑大列表；在途专用面板继续完整分页。
- Grok TTS 统一优先读取 `text`，再兼容 `input`、`prompt`，审核、在途预占和结算使用相同文本及 Unicode 字符口径。
- 图片上游用 HTTP 200 返回错误文本或错误对象时，按错误状态响应，不再按成功图片计费。尺寸错误返回 400，避免误停健康账号；错误出口保留脱敏，正常图片及提示文本保持原行为。
- CC Switch 导入支持 MiniMax Code、Kimi Code、DeepSeek Harness、Antigravity、Oh My Pi，以及 Claude Desktop/Pi 深链。Pi 系列未选择模型时显示提示并禁止导入。
