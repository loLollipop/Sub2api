## 更新

- 刷新令牌改为 Redis 原子消费，避免同一令牌被并发兑换；账号加载失败及时释放已占用槽位，兼容入口遵循账号错误策略。
- Sol 工具请求可从仅支持 Chat Completions 的账号切换至支持 Responses 的账号，耗尽时返回本地 400，不影响账号健康。
- 保留 Codex 加密工具参数和命名空间，规范页面上下文，拒绝非法 UTF-8；图片请求保留晚到错误状态，metadata 不再提前阻断换号。
- 修复 OAuth WebSocket 搜索启用时的重连和历史完整性校验，后续轮次失败不重放首帧；TTFT 遵循本地统计模式。
- Messages 显式关闭思考后先执行分组映射和上限，再校验最终出站值；保留省略默认值、GLM 原生路径和 count_tokens 边界。
- Gemini 正文过滤思考片段，Antigravity 并行工具媒体排序及 Pro Argon 配额隔离修正；定价正文与远端 hash 暂时不一致后继续重试，审计入队后及时唤醒本进程 worker。
