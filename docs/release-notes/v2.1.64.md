- 修复 320px 英文管理端用量页被日期工具栏撑宽的问题。页面 Grid 使用可收缩列宽，极窄屏统计卡片将图标放到数值上方，避免金额小数拆行；保留日期、粒度、刷新、记录切换与缓存明细操作。

- Anthropic 流式响应的裸输入占位零不再抹掉先前真实用量；明确的 cache/TTL 零值仍会清零。缓存别名、prompt 总量、显式 cache miss 和 cache hit 零值在原生及转换链路一致处理，避免客户端返回用量重复包含缓存或保留已清除的缓存桶。
- 公共设置加载失败后，普通请求退避 30 秒；保留强制刷新、并发合并、成功缓存与服务端注入配置。
