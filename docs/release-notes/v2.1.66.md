## 更新

- 密钥列表支持选择当前页面的多个密钥，批量修改分组、状态、额度、5 小时/每日/7 日限额、有效期和 IP 白名单。只更新勾选字段，支持额度归零、留空清除有效期和白名单；保存期间防止重复提交，逐项失败后继续并汇报成功/失败数。
- 批量更改分组明确替换全部分组路由，包括智能路由；没有勾选分组时保留原有路由。
- 注册页未同意协议时可以填写邮箱、密码、邀请码和优惠码；注册提交及 OAuth 仍受协议限制，设置加载和提交期间仍禁用输入。
- 新增 `GATEWAY_DISABLE_OPENAI_TRANSPORT_ERROR_COOLDOWN` 配置，默认 `false`，保持现有冷却行为。开启后仅跳过新增的 OpenAI 网关 transport 错误冷却，保留既有屏蔽、故障切换及 HTTP 错误策略；四套 Docker Compose 示例均支持该变量。
- 更新运行时二改来源检查点至 v2.3.89，原版仍为 v0.2.21；现有 Antigravity `/hub` User-Agent 保留。
