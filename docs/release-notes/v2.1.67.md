## 更新

- 修复登录邮箱身份回填失败导致的空指针，并保留首次绑定权益的原有判断。
- Gemini Chat 兼容入口支持结构化输出参数；OAuth 包装保留 JSON Schema 属性顺序和大整数。修复 Antigravity Schema 的 type/items 不一致。
- 修复 Responses 加密工具内容丢失、中途 system 消息角色转换、JSON Schema 默认 strict 值、Chat → Anthropic 的 metadata.user_id，以及 count_tokens 透传请求头重复。
- 保留 Codex additional_tools 声明 ID；临时分叉继承父会话缓存 key 时，保持父会话 namespace 与现有账号/API-key 隔离。
- HTML 统一禁用浏览器及 CDN 缓存；有每请求 CSP nonce 时不再因 ETag 返回 304，避免页面和 CSP 使用不同 nonce。
- 分组倍率/RPM 同步完整使用事务，重复用户以最后一项为准，保留显式 0 和清除语义；仅提交成功后更新本地 revision。
- CC Switch 模型列表和余额脚本正确处理 `/v1/`、代理路径和 query，避免重复 `/v1`。
- 渠道监控按公共真实时间轴定位；新分组显示在右端，历史缺口保留，质量历史按时间排序。
- Excel 导出每页请求 1000 行，瞬态错误每页最多尝试 3 次；取消后停止请求，成功重试不会重复追加记录。

保留本地主题、原生厂商路由、智能路由、真实终态用量与计费、0.15 倍率和有界排空约定。错误请求整单免收、新定价/统计迁移、调度成员查询改造及此前延期模块未引入。无依赖、数据库迁移或生产配置变更。
