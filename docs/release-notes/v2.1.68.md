## 更新

- 支持 GPT-6.1 Terra、GPT-6.2 Sol/Astra 和 Ultra Fast，贯通 HTTP、WebSocket、协议桥接及 Codex 元数据；Ultra Fast 支持渠道倍率覆盖和分组强制策略。
- 补齐 Fable/Mythos 5.2 的模型、Bedrock、thinking、effort、采样与标准/Fast 价格；支持 Gemini 4 Carbon 协议及 Carbon/Hydrogen 价卡，Vertex us/eu 路由和默认区域价格因子。
- 30 分钟/12 小时缓存用量贯通转换、存储、计费和界面，保留 aggregate、显式零及真实终态语义。账号成本与客户扣费分别统计，修复历史 rollup 合并。
- Gemini 同账号重试次数可配置；保留签名降级独立预算，部分输出或收费结果后不重放。Messages 断连排空采用固定期限，补齐多行 SSE 错误帧脱敏和协议工具兼容。
- 引入 HTTP 请求体共享内存预算、自动定额及 cgroup 路径约束；耗尽返回 503 和 Retry-After，完成或取消后释放。
- AG 支持主动查询额度，后台刷新保留账号行与已有额度；Key 列表与用量独立加载。用量列表精简关联字段，公告按需加载摘要、列表和详情，CSV 导出保护公式文本。

保留本地主题、原生/智能路由、0.15 倍率、显式零价和真实终态扣费，不恢复退役模块。新增迁移 271–275：Ultra Fast、缓存 TTL 字段、rollup 保留边界及 Key 用量覆盖索引；旧迁移不改。运行依赖版本未变，go.sum 仅补生成工具校验和。
