## 更新

- 用户 CSV 和管理员 XLSX/CSV 导出遵守 HTTP 429 的 Retry-After，支持取消、有限重试和总等待预算；固定导出筛选，检测分页变化后重新采集一次，避免下载已知不完整的数据。
- 登录状态查询合并同会话并发请求，成功结果复用 5 秒；可见页面每 90 秒刷新，后台标签暂停，恢复可见时补查。兑换、返利转余额和个人资料页面即时刷新，防止旧请求覆盖新会话或新结果。
- Gemini Chat/Responses 桥接可从临时错误前奏恢复并交付后续正常输出；只有有效成功终态才能撤回错误。补齐命名 SSE 错误和 Google flat status 观察，保留真实用量及已输出或收费后的禁止重放约定。
- gzip/zstd 响应先关闭网络以中断阻塞读取，再同步释放解压器；关闭幂等。OpenAI 非流式协议错误明确标记响应完成，避免 handler 追加第二段错误体。
- 管理员合规确认不存在时不缓存负结果，使其他实例新保存的确认及时可见；降智历史左对齐并保留时间顺序。
- Ops 错误日志缺省保留期调整为 7 天，已有显式设置及 0 值保持原义。
- 更新检查的二改版本与 commit 检查点同步推进到 v2.3.113，与维护记录一致，避免重复提示已审查的旧更新。

保留本地主题、路由、0.15 上游倍率、显式零价和真实终态计费。无新增或修改的 SQL 迁移，运行依赖版本不变。
