选择性同步二改 v2.3.158 和原版 v0.2.25，接入 basketikun/infinite-canvas 的原版图片画布。

## 更新

- 恢复二改的同源 iframe 入口，内置原 React 无限画布，支持图片生成、参考图编辑、提示词节点、连线、尺寸与质量选择、图片上传、下载和画布导入导出。仅开放生图，不提供视频、音频或 Agent 功能。
- 用户选择当前有权访问的生图分组，首次明确点击「创建并进入」后创建单组专用 Key。已有有效 Key 复用，失效或撤权不会自动换 Key。凭据仅通过同源消息握手保留在内存，项目和图片按用户保存在当前浏览器。
- 完善 OpenAI 错误透传、上下文容量错误和 compact 流终态，兼容管理员规则，并对错误字段、上游地址和凭据执行边界检查及脱敏。
- Messages、Chat Completions、Responses、Gemini 无账号时返回稳定提示；内容审核总开关关闭时不累计违规或自动封号，前后端行为一致，新配置的 cyber_policy 默认不计入自动封禁。
- 控制台和画布随 Go embed、Docker 与 Release 一起构建分发，附带画布 MIT 许可证。
- 更新画布锁定依赖，修复发布检查发现的高危依赖告警，并将画布生产依赖纳入独立 CI audit。

沿用现有生图分组和计费。无 SQL 迁移或生产运行配置变更。画布数据不跨设备自动同步，清理浏览器站点数据前请先导出。

## 验证与范围

本地控制台相关测试 55 项通过，双源后端定向回归记录 1308 个测试/子测试通过事件；Vue/React 类型检查、生产构建、前后端定向 lint 和 Linux embed 构建通过。实际编译界面的 12 项浏览器验收通过，覆盖生图与参考图编辑、错误不重发、账号隔离、上传下载和 320px 窄屏，使用隔离 API fixture，没有付费上游请求。发布按精确提交 CI、制品身份、备份实际恢复及线上健康验收。
