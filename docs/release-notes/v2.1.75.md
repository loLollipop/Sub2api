选择性同步二改 v2.3.175，修复 Claude 历史签名、压缩参数与错误信息显示，并优化请求改写和推理缓存。

## 修复

- 带真实签名的 Claude 历史思考始终交由上游验签，不再因本轮关闭 thinking 而被删除；保留无签名历史兼容和 Claude 5.5 的有效加密块。
- `compact-2026-01-12` beta 可正确携带 `context_management`，避免压缩触发器被剥离。
- Responses Lite 对 JSON `null` 不再触发 nil map 写入 panic，保留入口对象校验。
- 错误信息保留明确的 Anthropic 参数名及官方帮助/申诉链接，继续隐藏中转地址和凭据；补齐 URL 编码密钥路径的脱敏，内部诊断和分类证据保留。
- 监控回填跟随数据库中更早的持久游标，避免落后实例重放已完成的历史。

## 优化

- Responses item ID/call_id 清洗及 Grok 字段删除改为单遍收集、一次结果分配，保留原请求与宽松 JSON 排版语义。
- DeepSeek 原生推理缓存的大值透明 gzip 压缩，保留用户 Key/会话/模型隔离、独立 Redis、TTL 和旧明文兼容；损坏或超限值按原有未命中处理。
- 静默拒答观察器在结果已确定后跳过重复解析；分组策略快照最长缓存由 10 分钟缩短为 30 秒。

本地同步验收通过 611 个顶层 Go 测试、包含子测试共 1,701 项，以及前端生产构建和 Linux embed 构建。发布按精确提交 CI、安全检查、正式归档/GHCR 校验、备份实际恢复和受控切换流程执行；最终发布及生产证据单独保存。未调用付费模型或生图接口。
