## 修复与优化

- Redis 连接池采用 FIFO 轮转、空闲连接上限、独立池等待超时和连接寿命回收。现有显式参数继续优先，独立 reasoning 池保留调用方 deadline 和无预热行为；配置示例补齐新选项。
- 异步计费入队前复制请求级元数据、公开模型和映射字段，并复制可能引用大请求体的短字符串，避免队列持有已结束请求的上下文，或 Gin 复用后记录下一次请求的模型。保留计费同步兜底、在途余额引用和预授权所有权。
- 监控直方图 +Inf 溢出标记不再显示成真实的超大毫秒值；溢出分位值仍属于分桶近似。前端拦截负数、非有限值和历史 sentinel。
- Ops WebSocket 校验 HTTP(S) Origin 与请求 Host，停止信任 X-Forwarded-Host；拒绝全网段代理信任并规范 IPv4-mapped CIDR，保留既有端口和缺失 Origin 策略。
- 登录及 OAuth 发起/回调共用站内跳转校验，兼容重复 query 参数，拒绝反斜杠和控制字符；后端 OAuth 跳转校验同步收紧。
