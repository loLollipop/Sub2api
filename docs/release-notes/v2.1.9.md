# v2.1.9

- 同步二改上游 2.1.7—2.1.9 的已审查增量；使用本项目数字版本号，保留充值、计费与安全定制。
- 流式输出失败、缺失终止事件及上游嵌套 524 正确进入错误统计；超时提示移除上游 HTML 和域名细节，保留首输出前切换及已有终止帧、usage 规则。
- 客户端主动取消后的计费用量排空不计入上游失败 SLA；普通 HTTP 524 的客户端提示同样净化。部署回滚未成功恢复配置时禁止重启候选版本。
- 请求取消时及时释放在途跟踪器，保留本地无竞态快照、命名空间和原子 Redis 清理。
- Grok 普通文本输入走低分配快速路径，复杂工具、图片、转义或重复字段仍走原有规范化。
- 日志请求/上游 ID 可以点击精确筛选并跨页保留，错误列表补齐相同筛选参数。模糊和前缀搜索仍待索引及性能验证，不新增数据库迁移。
- 暂缓上游质量检测迁移：旧 Pelican 计划可能未经同意发送上游密钥到外部服务，且删除旧暂停恢复路径。继续保留现有检测和恢复行为，不自动切换检测服务。
- 保留原有 0.15 倍率、余额、充值页面、owner 隔离及先前暂缓项；生产迁移模式保持 validate，在线更新和余额预扣仍关闭，可切回 2.1.6 二进制。
