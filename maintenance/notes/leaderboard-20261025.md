## 数据与访问控制

`GET /api/v1/leaderboard?period=day|week|month|year`，默认本周。时间边界和统计时区统一按服务器配置，使用半开区间；周期为自然周期截至当前时间，上期为上一自然周期相同已过时长，且不越过当前周期开始。

按 `requested_model` 汇总，空值回退 `model`；Token 为输入、输出、缓存创建和缓存读取之和。响应只有模型级聚合，不含用户、密钥、账号、分组、成本或上游映射。前期独有模型保留，用于正确计算名次变化；无前期用量显示新上榜，不伪造增幅。

入口由公开设置控制，但 API 每个请求独立直接查数据库中的两个访问开关，绕过 settings 仓储缓存；关闭、数据库错误或缺少读取能力时拒绝访问。需认证时匿名返回 401。响应 `Cache-Control: no-store`；路由具备公共 IP 限流、OptionalJWT 和后台模式限制。

聚合结果按周期缓存 60 秒，singleflight 合并并发查询；跨时间桶或周期边界失效。共享统计查询最多 30 秒；取消单个访客不影响其他共享读取者。

SQL 直接读取当前保留的原始 usage_logs，按索引可用的半开时间区间一次分组，不混入 dashboard 汇总。现有汇总无法证明迟到写入已被包含，且特殊时区边界不能可靠复原；最终方案因此明确使用 raw-only 口径。页面中英文说明“仅统计当前保留的原始用量明细，已清理的历史不计入榜单”。无需新增迁移或改变汇总写入配置。

自然日期先按 UTC 日历运算，再按真实时区区间解析首个存在的日期瞬间，避免 DST 跳过午夜时回退前一天，也保留重复午夜的第一次。新增 Havana 和 Santiago 回归；缓存日期边界采用相同规则。

复核指出 Go 的 POSIX 时区外推在闰年末可能返回不晚于当前游标的 ZoneBounds 终点；已保证扫描继续推进，并增加纽约、哈瓦那、巴黎及悉尼跨闰年边界的有超时保护回归。
