# Sub2API 2.1.38

重新设计默认首页：左侧圆形站点 Logo 和品牌，右侧集中导航、语言、主题和圆形头像；使用暖灰背景、橙色渐变、轻量品牌浮动效果，将 API 接入示例移至下方独立区域。站点名称不添加尾随句点，配置的副标题、Logo 和文档链接继续生效。

顶部按首页、控制台、模型广场、排行榜、接入指南、文档排列。模型广场与排行榜遵循系统功能开关，访问继续由原有路由和后端控制登录要求；选中项仅强调文字。窄屏导航可横向滑动，支持深色模式、键盘操作与减少动态效果偏好。

保留自定义 HTML、外部首页和精简首页模式，以及账户菜单、登录/管理员跳转、API 格式切换、复制示例和法律页链接。本轮无后端业务、数据库迁移或依赖变更。

发布前验证包括首页、共享导航、功能访问和翻译完整性回归，TypeScript、ESLint、生产构建及多尺寸浏览器检查。GitHub CI、制品校验、GHCR 身份和生产验收结果另存发布证据目录。
