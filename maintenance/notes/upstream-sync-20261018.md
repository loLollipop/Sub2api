## 暂缓与边界

- `879d623b3`, `e57fc306e` 的自动 DeepSeek 搜索执行丢弃可计费 Search 结果，SSE 和最终答案传播尚不完整，并依赖暂缓的 DSML，故不导入。独立 Search/Fetch 仅使用账号自身凭据，保留现有分组搜索定价。
- 上述提交与 `56e0379fe`, `dbc035f24` 的专用分组搜索凭据需要数据库字段、缓存/投影/DTO/密钥不回显完整支持。来源迁移 260 与本地已应用的 260 冲突，未来须新增 267+，本次不替换历史迁移或添加不完整 UI。
- `783a4773b` 的 DSML 后续与 `acb60bfa5` 的全局 call-ID 范围扩张维持之前暂缓，不扩大既有正规化范围。
- 公网管理探测使用隔离的标准 TLS transport，以保证 DNS 与实际 socket 绑定；不会验证账号配置的 TLS 指纹一致性。受信任 OAuth 插件使用自身网络实现，属于插件信任边界。
- SMTP 内网服务器及私网账号测试现在会被拒绝；CRS 内网需要管理员在 CRSHosts 精确指定。生产配置本轮不自动放宽。
- 4096 为估算下限，并非任意上游成本的保证；预留功能及 fail-closed 默认开关不变，示例配置补充说明。
- 无数据库迁移、依赖变化或外部付费 API 调用。保留原生厂商、本地计费与充值入口；LinuxDo referral、多邀请码及用户撤销的框架不恢复。
