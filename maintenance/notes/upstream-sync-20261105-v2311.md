## 适配时修正的问题

模型广场源实现只比较首档，可能漏掉第二档价格、1h 缓存及显式零价。适配通过解析后的配置存在性识别覆盖，并验证配置参考各档与实际计费一致、不会污染其他分组的目录缓存。前端同时修正隐藏账号倍率列时丢失唯一数值，以及小倍率舍入为零的问题。

图片代码经独立审计复现八类问题，均已修正并保留回归：

1. 渠道、分组或区间显式缓存价覆盖所有缓存 token，清除继承的独立图片缓存价；区间倍率同时作用于图片缓存。
2. 图片缓存用量由公共解析器读取，API Key/OAuth、JSON/SSE 均可拆分；缓存图片不再重复作为普通图片输入收费。
3. 有有效用量的 completed 帧作为完整快照，允许个别字段归零；全零终态继续遵循本地保留渐进用量的既有契约。
4. HTTP 200 响应体内的不可重试业务错误写回对应错误状态与正文，避免空 200。
5. 原生流首次输出前的传输错误进入已有 failover；已写 partial 后禁止重试，断开后继续排空计费数据。
6. 独立图片缓存价区分缺失与显式零，零价免费，缺失才回退普通缓存价。
7. GIF JSON 数值验证整数性与溢出；指数形式整数可用，小数不再静默截断。
8. 管理员测试补齐原生端点 404/405 回退，采用实际图片转发的 Images HTTP profile。

发布审查另发现原生 SSE `event: error` 与正文拼接后无法解析，以及可重试错误提前写出的问题。解析行与转发行现已分开，首次输出前由统一处理器保留用户错误或触发服务端错误重试；partial 已输出后发送错误且不重试。16 个定向场景覆盖有无 event 行、两种读取循环、用户/服务端错误和 partial 状态，并验证后续连接中断不会覆盖原始错误。
