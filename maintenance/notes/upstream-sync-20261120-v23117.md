## 采用及适配

- **GPT-6.2 Codex 缓存前缀**（`1b13f0a0b`）：普通 GPT-6.2 请求将稳定指导保留为 input 开头的 developer 消息，system 角色转为 developer，避免把同一段指导复制到 instructions。调用方明确传入的 instructions 保持本轮语义；默认前缀不重复插入，previous_response_id 续接时不再补前缀。服务端模板无调用方指导时也可使用稳定前缀。compact、旧型号和透传路径维持原有契约。
- **Gemini thinking 档位价格**（`86c60ba90`、`0fd1ca9de`）：先查精确档位，再查同一供应商的基础型号；Google 模型资源路径可解析到公共型号，显式供应商前缀不能落到其他供应商或无前缀价卡。加入 Hydrogen high/low/medium/xhigh/sonar，保留本地 Carbon/Argon 的 tiered 等已有别名。
- **本地静态价格适配**：回归发现动态目录拒绝供应商前缀后，本地 BillingService 仍会按裸型号静态价兜底。对明确带供应商前缀的 Gemini thinking 别名关闭该跨范围兜底；存在同供应商动态基础价时继续使用。普通型号及 Google 资源路径的本地静态价保留。源测试中“目录没有该型号”的场景隔离静态价 fixture，另测生产静态价和供应商隔离，避免把本地已有价卡误删。
- **请求重复字段安全修复**（`65d42da96`，GHSA-p3r4-jcm3-2hph）：所有本地网关 HTTP 链在模型白名单之后、合成路由和调度之前检查重复字段，覆盖同值重复、转义/大小写折叠、嵌套对象和 multipart 标量；合法列表和工具参数内大小写不同的自定义键保留。JSON 按正文识别并处理 BOM，不能通过伪装 MIME 或 multipart 前导 JSON 绕过。拒绝采用对应入口协议的 400 错误格式。
- **本地读体契约**：保留共享正文内存预算的 503/Retry-After 和取消请求的 499；文本接口在新预读之前应用其较低正文上限，超限仍为 413。本地 requestmodel.go 中已有的 JSON/multipart 候选解析优于来源版本，保持原实现。
- **补全 WebSocket 安全修复**：二改正式版本只带 HTTP guard，未包含其说明涉及的完整 WS 调用链。本轮从原仓库 v0.2.24 `5c2982a81b46e2142d0143d2f83c1ce9c4da1d24` 抽取配套 guard 和回归测试：首帧、续接 turn、公共 service 入口及 passthrough 的所有文本/二进制帧（含 session.update）在解析/改写/转发前拒绝重复字段，关闭码 1008。重复 previous_response_id 在恢复重连前拒绝，正常恢复语义保留。

原仓库配套安全修复参考 `2b67d1ede`、`d270d6434`、`ce86c1b30`、`263a13f16`、`a436766de`。这些独立切片不代表完成原仓库 v0.2.24 全量同步；原仓库已审阅正式检查点仍为 **v0.2.23**。
