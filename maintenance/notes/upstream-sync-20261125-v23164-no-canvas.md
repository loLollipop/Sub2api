## 无限画布移除范围

移除 `/infinite-canvas` 路由、导航与仪表盘入口、Vue 宿主、专用 Key 设置及握手工具、双语文案、后端 `/canvas` 静态代理和专属 CSP 代码、嵌入辅助函数，以及 `canvas/` 下 126 份已跟踪 React 源码、资源、锁文件和说明。另移除 3 份未纳入 Git 的源项目测试。现有导航测试恢复画布入口不存在的约束。

控制台 build、Makefile、Docker、GoReleaser、CI 与 security audit 的画布步骤和许可证拷贝一并移除。当前生产构建只有控制台资源，无 `dist/canvas`、画布 URL 或画布环境变量。旧 `/infinite-canvas` 和 `/canvas/` 页面在实际构建的控制台中进入正常 404；源安全头回归仍检查旧路径不获得嵌入放行。历史发布记录及已发布归档保留，2026-11-24 的接入记录为历史状态，本记录取代其恢复决定。

本地 `canvas/web/node_modules` 的递归删除被自动审批两次拒绝，包括缩小到该明确目录的命令，工具仅返回 `blocked by policy`，未提供更具体原因。该约 434 MB 的未使用依赖目录仍在磁盘上，未加入构建和发布；没有通过其他工具绕过拦截。此项物理清理尚未完成，不能声称整个本地 canvas 目录已删除。业务源码、入口及运行接入均已撤下。

没有删除现有生图分组、用户 API Key、浏览器本地项目或生产数据，也未清理 Git 历史、发布验收资料及回滚归档。源码删除可从基线提交恢复。
