# 使用记录修复与代码清理（2026-11-06）

## 修复结果

- 管理端默认时间范围稳定显示“近24小时”。原实现用挂载时重新生成的时间范围逐秒比较，跨秒挂载会把默认范围误判成自定义；现在由页面保存快捷范围类型，图表工具栏和筛选区共享该状态。自定义显示“自定义”，完整起止时间只在面板中编辑，仍保留秒精度。通过 URL 指定的日期保持自定义，刷新不滑动；重置恢复近24小时。
- 管理端和用户端的使用记录保留独立的“思考强度”列，紧随“模型”列，并保留独立列设置入口。管理端保留请求与实际转发强度，例如 `Max → XHigh`；模型映射链、上游模型审计和 Excel 的独立导出字段继续保留。用户端只展示接口已有字段。
- API Key 和账户搜索增加请求序号校验；清空、选择结果、切换用户、卸载组件时取消待执行搜索并作废旧响应。选择用户立即应用筛选，API Key 预加载不再阻塞筛选生效。
- 管理端错误请求表只接受最新一次分页、排序和筛选请求的结果；旧请求不能覆盖新结果或提前结束新请求的加载状态。修改筛选、刷新或按请求 ID 下钻会使缓存失效，离开页面后忽略未完成响应。
- 使用表直接读取显示参数，移除将响应式 props 固定为初始值的两个别名。
- 开发指南中的 Go 版本更新为当前 `go.mod`、CI 和 Dockerfile 使用的 1.27.3。
